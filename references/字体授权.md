## 一个需要说明的出入：Roboto Mono 不是 Apache-2.0

Roboto Mono **早期确实是 Apache-2.0**，后来随 Roboto 系列一起改为 OFL-1.1。本仓库当前收录的是
**改版之后的构建**，因此按 OFL 标注。判断依据不是传闻，是二进制自己写的和官方源现在的状态：

1. **字体二进制内嵌声明**（`name` 表 nameID 13 / 14，用脚本直接读 TTF 得到）：

   ```
   RobotoMono-Regular.ttf  version 3.001
     license : This Font Software is licensed under the SIL Open Font License,
               Version 1.1. This license is available with a FAQ at:
               https://openfontlicense.org
     licenseURL: https://openfontlicense.org
   ```

   `RobotoMono-Medium.ttf` 同为 version 3.001、同一段 OFL 声明。

2. **Google Fonts 上游现状**：`apache/robotomono/` 目录已不存在（请求返回 404），
   字体移至 `ofl/robotomono/`，`METADATA.pb` 中 `license: "OFL"`。

3. 两份字体的 `copyright` 字段均为 `Copyright 2015 The Roboto Mono Project Authors`，
   与上游 `ofl/robotomono/OFL.txt` 首行一致。

如果后续换入的是**旧版 Apache 构建**（version 2.x 及更早），则须相应改用 Apache-2.0 全文，
不能沿用本文件。判断方法同上：读 `name` 表，别靠记忆。
